The package's own code is MIT (see LICENSE). The icon shapes are copied from these sets through
[Iconify](https://iconify.design/) and keep their own licenses. Every app that shows the icons links
to an "Icon credits" page built from `ICON_CREDITS` (`src/credits.ts`).
