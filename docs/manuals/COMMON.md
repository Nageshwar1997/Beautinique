# MANUAL: Common (kai apps ke saajhe features)

> **Status:** v1.0.0 (2026-11-22). Jo feature kai apps me bilkul ek jaisa chalta hai, uska manual yahan ek hi baar; har feature ke saath likha hai ki wo kis-kis app me hai. Feature bante hi Claude usi PR me ye file update karta hai (D-440).

## Niyam

1. **Kab yahan:** feature do ya zyada apps me bilkul ek jaisa ho (wahi screen, wahi kadam). Misaal: sign-in, authenticator, session ka band hona, theme, khabrein, Credits page.
2. **Kis-kis app me:** har feature ke saath apps ki list. Feature kisi naye app me jude ya kisi se hate, to list usi PR me badalti hai.
3. **Thoda farak ho to:** saajha hissa yahan; jis app ya role me farak hai, wo farak us role ki file me, yahan ki link ke saath.
4. **Role ki file me dobara nahi:** role ki file me sirf ek line, misaal "Sign-in: [COMMON.md](COMMON.md#sign-in)".
5. Baaki niyam aur har feature ka dhaancha [README.md](README.md) jaisa: kab kaam aata hai, kadam, dhyaan rahe, niyam ki links.
