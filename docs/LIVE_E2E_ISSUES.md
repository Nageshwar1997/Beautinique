- **Jaancha (Claude, live, 2026-11-13 ~02:55–03:15 IST):** curl aur in-app browser se, bina account ke: backend ke `/health`, `/ready`, `/status`, `/wake`, JWKS; har app ke proxy (`/api/v1/...`) se gateway ke pehre (origin secret, app allow-list, CSRF Origin, fail-closed 401, validation, rate-limit headers, cookies, OAuth start/callback); 11 apps ke pages, security headers, manifest, `noindex`; customer ke SSR pages; 360 px pe admin aur customer.

Production pe account banana aur password daalna Claude ke liye mana hai; ye owner karega (§4). Inke flows CI ke poore tests (identity, notify, core, bundle, apps ke e2e) me har PR pe chalte hain.
- **Backend version:** pehli jaanch ke waqt live `7c0fa36` tha (ObjectId release ka deploy `7684d8b` purane data pe gira, MEMORY sabak 43). `380eef8` (PR #68) 2026-11-12 22:25 UTC pe Live hua; uske baad ki jaanch §3a me.

## 3. Pass hua (live, bina sign-in)

- **Backend:** `/health` 200, `/ready` 200 (redis, identity, notify, core ok), `/status` 200 (payments `not-running`, jaisa abhi hona chahiye), `/wake` 204, `/.well-known/passport-jwks.json` ES256 key.
- **Gateway ke pehre (customer proxy se):** bina origin secret seedha Render pe 403 `FORBIDDEN`; galat `Origin` (POST), galat/anjaan/missing `X-BQ-App`, doosre app ka header → 403 `APP_NOT_ALLOWED`; signed-in routes (`/iam/me`, `/auth/sessions`) aur permission routes (`/iam/roles`, `/iam/grants`) bina cookie 401; nakli access cookie 401; customer app se ping read 403 (app ki permission nahi); khaali body pe 400 `VALIDATION_FAILED` field-wise (login, sign-up code, invitation code); galat challenge/login id 400 (500 kabhi nahi); kharab JSON 400 `BAD_REQUEST`; anjaan route 404; har jawab me `X-Request-Id` aur `Cache-Control: no-store`/`private, no-store`.
- **Rate limit:** classes `public` 600/60 s, `read` 600/60 s, `session` 600/300 s, `auth` 30/300 s, `otp` 10/600 s, `RateLimit`/`RateLimit-Policy` headers.
- **Session cookies:** refresh/logout pe teeno cookies saaf (`__Host-bq_customer_at` HttpOnly, `__Secure-bq_customer_rt` path `/api/v1/auth` SameSite Strict, `__Host-bq_customer_hint`); bina session refresh 401 `SESSION_EXPIRED`, logout 200.
- **OAuth (customer):** providers list (google, linkedin, github); Google start 303 PKCE (`code_challenge`) + `state` cookie (10 min, HttpOnly); galat state ka callback → `/sign-in?oauth=expired` aur cookie saaf; anjaan provider 400; `oauth/sign-up` bina cookie 400 `OAUTH_SIGN_UP_EXPIRED`.
- **Apps:** 11 apps 200; har ek pe CSP `frame-ancestors 'none'`, `X-Frame-Options DENY`, HSTS, `nosniff`, Referrer-Policy, Permissions-Policy; internal apps pe `X-Robots-Tag: noindex, nofollow`; manifest 200 (`application/manifest+json`); 9 khaali apps "Coming soon".
- **Customer SSR:** home, sign-in, sign-up, forgot-password, terms, privacy, account, security, devices, invitation 200 sahi titles ke saath; private pages `noindex`; anjaan page asli 404; home pe console error nahi; 360 px pe sideways scroll nahi.
- **QA report ke fix live:** QA-CUS-001 (`/account` ka title "Account"), QA-ADM-001 (admin 360 px pe header 360, scroll nahi).
