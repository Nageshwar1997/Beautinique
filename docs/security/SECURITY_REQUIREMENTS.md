# SECURITY REQUIREMENTS: Beautinique

> **Status:** v1.3.2 (2026-11-22). Security ke niyam, module-wise. Cheezein ek-ek karke judti hain.

## 0. Kaise likhein

- Har niyam: **Id**, **Niyam**, **Kis module pe**, **Kahan se** (OWASP ASVS 5.0.0 ka chapter), **Test kaise**, **Release** (`R1`, `R2`, ya `R1; R2 me: ...`). OWASP Top 10:2025 aur OWASP API Security Top 10 2023 ka naksha §2 me.
- Pehle poore system ke niyam (auth, sessions, API, data, secrets, logs), phir har module ke.
- **Number:** SR-001, SR-002 ... kram se. Ek baar diya number kabhi badalta nahi aur dobara use nahi hota.
