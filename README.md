# Beautinique

Indian beauty-only e-commerce marketplace: apps for every role, backend services and shared npm packages, in one monorepo. Education and portfolio project, built like a production product.

The project is being rebuilt from scratch.

- Docs: [docs/](docs) (being rewritten); the previous docs are in [docs-old/](docs-old), kept for reference.
- The previous code is in the `*-old/` folders (`backend-old`, `frontend-old`, `packages-old`, `scripts-old`, `configs-old`, `infra-old`), kept for reference. It no longer installs, builds or runs from the root.
